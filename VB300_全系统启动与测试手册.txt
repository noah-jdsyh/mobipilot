================================================================================
  第一部分: 设备连接总览
================================================================================

┌───────────── 笔记本 ───────────────┐
│                                   │
│ USB1 ← FTDI线 ← INS5715DAA RS232-1 │  230400bps BD DB 0B
│ USB2 ← PCAN-USB ← CAN4-H/CAN4-L   │  500kbps CAN 收发
│ RJ45 ← 千兆交换机                  │  192.168.1.50/24
│          ├── LiDAR #1 192.168.1.33 │
│          └── LiDAR #2 192.168.1.34 │
└───────────────────────────────────┘

底盘供电: 12V DC → INS5715DAA + 千兆交换机 + 2×LiDAR


================================================================================
  第二部分: CAN 接口初始化 (每次开机执行一次)
================================================================================

sudo ip link set can0 down
sudo ip link set can0 type can bitrate 500000
sudo ip link set up can0
candump can0 | head -3                     # 确认有 EPS/MCU/EHB 帧


================================================================================
  第三部分: 组合导航 (INS5715DAA) 启动
================================================================================

1. 确认串口:
   ls /dev/ttyUSB*

2. 验证数据:
   sudo cat /dev/ttyUSB0 | xxd | grep "bddb 0b" | head -1
    # 应看到 bddb 0b 帧头

3. 启动 ROS2 驱动:
   pkill -9 -f ins_node 2>/dev/null
   source /opt/ros/humble/setup.bash
   source ~/vb300_ws/install/setup.bash
   ~/vb300_ws/install/vb300_nodes/bin/ins_node \
     --ros-args -p port_data:=/dev/ttyUSB0 -p baud:=230400

4. 验证数据:
   ros2 topic list | grep ins           # 应看到 /ins/pose /ins/odom /ins/fix /ins/status
   ros2 topic echo /ins/pose --once     # 露天有 GNSS 时输出 UTM 坐标

   ⚠ 室内无 GNSS → pos_valid=False → 不发 /ins/pose, 日志显示 UNINIT
     露天有卫星 → 自动开始发布
    

================================================================================
  第四部分: 激光雷达 (Mid-360) 启动
================================================================================

1. 配网口:
   sudo ip addr add 192.168.1.50/24 dev enp52s0 2>/dev/null

2. 验证连通:
   ping 192.168.1.33 -c 1
   ping 192.168.1.34 -c 1

3. SDK 验证 (看原始点云):
   /home/cabr/Livox-SDK2/build/samples/livox_lidar_quick_start/livox_lidar_quick_start \
     /tmp/mid360_dual.json

4. ROS2 驱动 (需要先解决 livox_ros_driver2 配置):
   source ~/vb300_ws/install/setup.bash
   ros2 launch livox_ros_driver2 rviz_MID360_launch.py
   (或待 UDP bridge 完善后使用)


================================================================================
  第五部分: 底盘 CAN 功能完整测试
================================================================================

  前提:
    底盘上电, 千斤顶架起四轮离地, 遥控器在手, CAN已配置
    若用 ROS2 方式: can_node 必须运行
      source ~/vb300_ws/install/setup.bash
      ~/vb300_ws/install/vb300_nodes/bin/can_node

  CAN ID 速查:
    ACU_General (0xCF008FB)       → 智驾发底盘 (控制)
    EPS_ACU     (0x18FB62F7)      ← EPS 反馈 (方向盘角度/故障)
    MCU_1_General (0x18F900EF)    ← 车速/油门 反馈
    MCU_2_General (0x18F560EF)    ← 档位/电机转速/就绪 反馈
    EHB_ACU     (0x18F40010)      ← 制动压力/故障 反馈
    EPB_ACU     (0x18F53C0C)      ← 电子驻车状态 反馈
    BMS_ACU     (0x18FF50E6)      ← 电池 SOC/电压/电流/温度 反馈

  ───────────────────  S1. 自动驾驶模式开关  ───────────────────
  ROS2:
    ros2 topic pub -1 /cmd vb300_interfaces/msg/ChassisCmd \
      "{gear: 0, auto_enable: true, epb_release: true, steer_angle: 0.0, throttle_pct: 0.0, brake_pct: 0.0}"
  预期: 仪表指示灯变化/继电器声

  ROS2关闭:
    ros2 topic pub -1 /cmd vb300_interfaces/msg/ChassisCmd \
      "{gear: 0, auto_enable: false, epb_release: true, steer_angle: 0.0, throttle_pct: 0.0, brake_pct: 0.0}"

  ───────────────────  S2. EPB 驻车释放/拉紧  ───────────────────
  释放:
    ros2 topic pub -1 /cmd vb300_interfaces/msg/ChassisCmd \
      "{gear: 0, auto_enable: true, epb_release: true, steer_angle: 0.0, throttle_pct: 0.0, brake_pct: 0.0}"
  拉紧:
    ros2 topic pub -1 /cmd vb300_interfaces/msg/ChassisCmd \
      "{gear: 0, auto_enable: true, epb_release: false, steer_angle: 0.0, throttle_pct: 0.0, brake_pct: 0.0}"
  验证: ros2 topic echo /state | grep epb_applied

  ───────────────────  S3. 档位测试  ───────────────────

================================================================================
  第七部分: 键盘遥控 (测试用)
================================================================================

  pkill -9 -f keyboard 2>/dev/null
  source /opt/ros/humble/setup.bash
  source ~/vb300_ws/install/setup.bash
  ~/vb300_ws/install/vb300_nodes/bin/keyboard_teleop

  按键:
    W/S     油门 +/- 5%
    A/D     左转/右转
    空格     急刹 100%
    1/2/0   D/R/N 档
    P        EPB 释放/拉紧
    E        自动驾驶开/关
    Q        退出(自动停车+EPB)

  ⚠ 使用前确认: 千斤顶架牢, 遥控器在手, 车内无人

  关键参数速查

  传动比:    24.375 (方向盘780° / 前轮32°)

  LiDAR #2:   192.168.1.34
